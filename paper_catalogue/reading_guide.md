# Where to start: numerical linear algebra for deep learning

Reading priorities are an editorial recommendation based on fit to this project, not a ranking of paper quality. Accepted status comes from the official program; preprint years can differ from the conference year.

| Paper | Venue | Quantity | Computational idea |
|---|---|---|---|
| [PRISM: Distribution-free Adaptive Computation of Matrix Functions for Accelerating Neural Network Training](<https://openreview.net/forum?id=hwhvjhXC0m>) | ICML 2026 | Matrix roots, inverse roots and polar factors | Fit iteration polynomials to the current spectrum through randomized sketched least squares; use matrix multiplications for the main iteration. |
| [The Polar Express: Optimal Matrix Sign Methods and their Application to the Muon Algorithm](<https://openreview.net/forum?id=yRtgZ1K8hO>) | ICLR 2026 | Polar factor and matrix sign for Muon | Use matrix-multiplication-only polynomial iterations with minimax-designed coefficients and finite-precision stabilization. |
| [DASH: Faster Shampoo via Batched Block Preconditioning and Efficient Inverse-Root Solvers](<https://openreview.net/forum?id=ujeyxKwTGM>) | ICML 2026 | Shampoo inverse-root preconditioners | Batch preconditioner blocks into tensors; use Newton-DB iteration and Chebyshev approximations for inverse roots. |
| [Scalable Kronecker-Factored Fisher Approximation for Neural Network Parameter Sensitivity](<https://openreview.net/forum?id=pNe5fVK1tR>) | ICML 2026 | Structured Fisher information and sensitivity-aware low-rank factors | Matrix-free Fisher factorization retains off-diagonal structure; GFWSVD gives a curvature-weighted layer decomposition. |
| [Randomized Advantage Transformation (RAT): Computing Natural Policy Gradients via Direct Backpropagation](<https://openreview.net/forum?id=oVtiySvpXz>) | ICML 2026 | Regularized natural policy gradients | Use Woodbury to move the solve to advantage space, approximate it with randomized block Kaczmarz, then use ordinary backpropagation. |
| [FlashSketch: Sketch-Kernel Co-Design for Fast Sparse Sketching on GPUs](<https://openreview.net/forum?id=cCwxV6rSXF>) | ICML 2026 | Sparse sketches of large matrices | Co-design block-permuted sparse Johnson-Lindenstrauss transforms and a CUDA kernel for local accumulation and efficient memory access. |
| [Local Hessian Spectral Filtering for Robust Intrinsic Dimension Estimation](<https://openreview.net/forum?id=rJ2gMA21ZW>) | ICML 2026 | Filtered log-density Hessian trace and local intrinsic dimension | Apply stochastic Lanczos quadrature through Hessian-vector products to count near-zero-curvature tangent directions. |
| [Taming Curvature: Architecture Warm-up for Stable Transformer Training](<https://openreview.net/forum?id=DuNf2vPTTK>) | ICLR 2026 | Largest preconditioned Hessian eigenvalue during training | Warm-start power iteration with Hessian-vector products for online curvature tracking. |
| [Deterministic Bounds and Random Estimates of Metric Tensors on Neuromanifolds](<https://openreview.net/forum?id=Ssevs8KCsU>) | ICLR 2026 | Fisher metric-tensor quantities on neural parameter manifolds | Derive bounds in the low-dimensional probability core space and use a Hutchinson-based estimator with one backward pass per batch. |

| [TurboBoA: Faster and Exact Attention-aware Quantization without Backpropagation](<https://openreview.net/forum?id=HA0TnV8r7x>) | ICLR 2026 | Attention-aware quantization error compensation | Jointly quantize output channels using closed-form compensation, propagated-error correction and coordinate-descent grid refinement. |

| [DELTA4: Sparse Matrix-Vector Multiplication for Low Sparsity](<https://openreview.net/forum?id=ah9xkFXCV6>) | ICML 2026 | Sparse matrix-vector products in pruned LLMs | Co-design a compact sparse format and GPU kernel to reduce bandwidth overhead at moderate unstructured sparsity. |

| [Purifying Shampoo: Investigating Shampoo's Heuristics by Decomposing its Preconditioner](<https://openreview.net/forum?id=kePsKwxvaV>) | NeurIPS 2025 | Shampoo eigenbasis and inverse-root preconditioning | Separates eigenvalue adaptation from eigenbasis estimation and schedules eigendecompositions using an error criterion motivated by warm-started QR. |
| [A Stable Whitening Optimizer for Efficient Neural Network Training](<https://openreview.net/forum?id=0T8i3uXq3O>) | NeurIPS 2025 | Whitened and normalized matrix-gradient updates | SPlus reuses a historical Shampoo eigenbasis and normalizes current gradients in that basis. |
| [SubTrack++ : Gradient Subspace Tracking for Scalable LLM Training](<https://openreview.net/forum?id=6geRIdlFWJ>) | NeurIPS 2025 | Time-varying low-rank gradient subspaces | SubTrack++ updates the projection subspace using Grassmann geometry and adjusts Adam statistics for projection changes. |
| [SUMO: Subspace-Aware Moment-Orthogonalization for Accelerating Memory-Efficient LLM Training](<https://openreview.net/forum?id=DIjRvEKOeG>) | NeurIPS 2025 | Orthogonalized gradient updates in a tracked subspace | SUMO computes an SVD in a low-dimensional adaptive subspace to reduce matrix orthogonalization cost. |
| [CDFlow: Building Invertible Layers with Circulant and Diagonal Matrices](<https://openreview.net/forum?id=XF4JM2MTSF>) | NeurIPS 2025 | Linear-layer inverses and log-determinants in normalizing flows | CDFlow factors layers into circulant and diagonal matrices, using FFT algebra for cheap inverse application and determinants. |
| [Spectral Estimation with Free Decompression](<https://openreview.net/forum?id=2CeGVUpOd7>) | NeurIPS 2025 | Eigenspectra of matrices observed through small submatrices | Free decompression uses free-probability structure to infer large-matrix spectral distributions from masked submatrices. |
| [Memory-Efficient Training with In-Place FFT Implementation](<https://openreview.net/forum?id=oWnAlRn3X1>) | NeurIPS 2025 | FFT transforms and frequency-domain parameter updates | A real-domain in-place FFT encoding preserves input/output dimension and reduces intermediate storage. |

| [Tiled Flash Linear Attention: More Efficient Linear RNN and xLSTM Kernels](<https://openreview.net/forum?id=b6H64u6TqI>) | NeurIPS 2025 | Chunkwise linear-RNN and mLSTM sequence operators | Tiled Flash Linear Attention adds parallelism within chunks to increase arithmetic intensity and reduce intermediate state traffic. |

Suggested paths:

- **Optimizer matrix functions:** Purifying Shampoo → SPlus → SUMO → Polar Express → PRISM → DASH.
- **Fisher / Hessian computations:** ASTRA → Matrix-free Fisher Factorization → RAT → online Hessian eigenvalue tracking.
- **Matrix-free spectral analysis:** Spectral Estimation with Free Decompression → Local Hessian Spectral Dimension → EigenScore.
- **Geometry and efficient algebra:** SubTrack++ → StelLA → LoRA-S → Cholesky product geometry → Trion.
- **Structured transforms:** CDFlow → Memory-Efficient Training with In-Place FFT.
- **Hardware-aware computation:** FlashBias → Tiled Flash Linear Attention → FlashSketch → DELTA4 → FlashSinkhorn.

Read each entry’s qualification before transferring an idea: a sampled Fisher, the empirical Fisher, a Gauss-Newton matrix and a loss Hessian are not interchangeable. Likewise, approximate attention and exact implementations of a changed attention operator are different claims.
